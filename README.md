## 협업 규칙

### 브랜치

- `main` — 배포/제출용. **직접 push 금지**
- 작업은 개인 브랜치에서 진행 후 PR로 병합

브랜치 이름 규칙:

```
feature/기능명
fix/버그명
```

### 커밋 메시지

```
feat: 새 기능 추가
fix: 버그 수정
docs: 문서 수정
refactor: 코드 구조 개선
```

### 주의사항

- API 키, 비밀번호 등은 **절대 커밋하지 않습니다** (`.env` 사용)
- 커밋 전 GitHub Desktop의 변경 파일 목록을 확인해 주세요
