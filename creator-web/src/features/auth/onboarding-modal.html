서비스 이용을 위해 약관을 확인해 주세요

필수 약관에 동의해야 서비스를 계속 이용할 수 있어요. 선택 동의는 언제든 변경할 수 있습니다.

약관 정보를 불러오는 중... 


          


          
        


        
        

          

            
            

              다른 사용자에게 보여질 이름이에요.

              피드백과 테스트 참여 기록에 이 닉네임이 표시됩니다.
            

          


          

            

              
              0/20자
            

            
            한글, 영문, 숫자 조합으로 최대 20자까지 입력 가능합니다.
          


          

            
            
            비슷한 직업군의 테스터를 찾는 제작자에게 추천될 때 쓰여요.
          


          

            

              
              0/50자
            

            
            비워 두고 나중에 내 정보에서 입력해도 괜찮아요.
          

        


        
        

          

            테스터 모집 조건을 맞추는 데만 쓰여요.

            다른 사용자에게는 공개되지 않고, 제작자에게는 통계로만 보입니다.
          


          

            
            

              
              
            

          


          

            
            

              
              
              
              
              
              
            

            만 14세 미만은 서비스에 가입할 수 없습니다.
          


          

            

              
              0개 선택
            

            여러 개 고를 수 있어요. 기기 조건이 있는 테스트를 추천할 때 쓰여요.

            

              
              
              
              
            

          

        


        
        

          

            

              
              0/5개 선택
            

            관심 있는 분야를 1~5개 선택해 주세요. 선택한 분야의 테스트를 먼저 추천해 드려요.

            

              
              
              
              
              
              
              
              
              
              
            

          


          

            

              
              0/10개
            

            써 본 툴이나 배우고 싶은 기술을 적어주세요. 이 툴로 만든 서비스의 테스트를 먼저 추천해 드려요.

            

              
              
            

            쉼표로 구분하거나 Enter 로 여러 개를 한 번에 추가할 수 있어요.
